# WRAPT-CTF

**WRAPT-CTF** 是一款面向 CTF 竞赛与安全教学场景的自动化 AI 解题平台，支持 `Web`、`Pwn`、`Crypto`、`Reverse`、`Misc` 五类任务，并通过多智能体编排、工具调用和本地 RAG 知识检索来协助完成侦察、分析与利用。

---

## 🌟 核心特性

- **多智能体协同**：主规划、协调、侦察、利用、验证、报告等角色分工执行，减少长流程任务中的上下文漂移。
- **Web UI + CLI 双入口**：默认提供 Web UI，也支持命令行直接启动任务。
- **本地 RAG 检索**：运行时同时加载知识库与技能库，支持按文档分块检索，并在启动阶段注入首轮知识上下文。
- **灵活目标输入**：支持 `192.168.0.1`、`192.168.0.1:8000`、`https://test.com`、`https://test.com:8000/path` 等形式，系统会保留原始输入并生成适合 AI 与约束层使用的目标候选。
- **结构化操作员上下文**：设置页中的公网反连地址、端口、SSH 账号与密码状态会进入 AI 上下文，供反连 Shell、OOB 外带和远程登录场景使用。
- **实时任务观测**：Web UI 可显示思考流、工具输出、RAG 命中预览和最终汇总出的疑似 Flag。
- **可中断任务运行**：当用户已手动验证 Flag 时，可直接在 Web UI 停止当前项目，避免继续等待总结或收尾阶段。
- **完整 WP 自动导出**：任务结束后自动生成 Markdown、JSON、DOCX 三种报告，其中 DOCX 为完整 CTF Writeup，可直接下载。
- **真实截图归档**：WP 会优先嵌入运行时终端截图、运行时浏览器真实渲染截图，并保留补充过程图。
- **报告自检与自动重建**：DOCX 生成后自动做可读性校验；下载前若发现损坏，会基于 JSON 自动重建。
- **模型稳态重试**：自定义 AI 接口在临时网关错误、HTML 错页等场景下会自动重试，降低一次异常直接终止任务的概率。

## 🧰 工具与依赖体系

### 1. 基础 CTF 工具链

由 [start.sh](start.sh) 负责安装并初始化。当前覆盖的基础能力包括：

- 网络与扫描：`nmap`、`masscan`、`rustscan`、`amass`、`whois`
- Web 与字典扫描：`sqlmap`、`ffuf`、`dirb`、`gobuster`、`nikto`、`wfuzz`、`wafw00f`、`httpx-toolkit`
- 连接与代理：`netcat-openbsd`、`socat`、`proxychains4`、`chisel`、`smbclient`
- 密码与爆破：`hydra`、`hashcat`、`john`
- 取证与隐写：`binwalk`、`foremost`、`exiftool`、`steghide`、`tshark`、`sleuthkit`、`testdisk`、`pcapfix`
- 漏洞检索与利用辅助：`exploitdb/searchsploit`
- 逆向与二进制：`radare2`、`gdb`、`ltrace`、`strace`、`checksec`、`patchelf`、`apktool`
- 基础运行环境：`default-jre-headless`、`ffmpeg`、`imagemagick`、`p7zip-full`、`dnsutils`、`file`


### 2. Web UI


当前 Web UI 支持：

- 创建任务与选择题型
- 目标输入支持 IP、IP:端口、域名、完整 URL
- 用户额外提示 / 题目简介输入
- 平台设置与模型设置
- 当前项目停止
- RAG 命中预览
- 工具输出与思考流监控
- 最终疑似 Flag 汇总展示
- WP 下载卡片与 DOCX 报告下载


###3. 运行逻辑摘要

平台当前的任务链路大致如下：

1. 解析用户输入的目标，保留原始地址并生成候选目标形式
2. 加载 `knowledge/` 与 `skills/`，执行首轮 RAG 检索
3. 主规划 AI 生成高层计划
4. 协调 AI 分发任务；若分发失败，系统会自动回退到内置 `Recon -> Exploit` 任务链，避免空转
5. 侦察、利用、聚合、验证、报告依次执行；模型临时网关异常会进入自动重试
6. 工具执行阶段可采集运行时终端截图与浏览器截图，作为 WP 证据资产
7. 从各阶段结果与报告中汇总疑似 Flag，并同步回 Web UI / CLI
8. 自动生成 Markdown / JSON / DOCX 报告，并在下载前进行自检与必要时重建

## 📝 报告与 WP 导出

任务完成后，平台会生成报告：

- `*.md`：Markdown 摘要报告
- `*.json`：结构化报告数据
- `*.docx`：完整 CTF Writeup（WP）

当前 WP 主要包含：

- 执行摘要、方法论、详细解题过程
- 结构化发现与修复建议
- 关键命令、代码摘录、模型调用统计
- 运行时真实终端截图
- 运行时真实浏览器渲染截图
- 补充过程图、证据缺口与质量检查

下载与可靠性特性：

- Web UI 提供 `WP 下载` 卡片，任务结束后可直接下载 DOCX
- DOCX 生成后会自动做可读性校验
- 若下载时发现文件缺失或损坏，后端会基于同名 JSON 自动重建后再返回

## 🧠 知识库与技能库

当前已覆盖的知识方向包括：

- Web：登录表单、响应差异、SSTI/LFI、上传、SSRF、XXE、下载/路径穿越、原型污染、反序列化、文件包含、命令执行链
- Reverse：二进制分诊、动态调试、VM 模式、Patch 策略、反调试
- Crypto：RSA、PRNG、ECC、格攻击、流密码初筛
- Misc：批量解码、多层压缩、隐写与提取工作流
